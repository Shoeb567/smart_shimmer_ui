## 1.0.0

* 🎉 Initial production release of `smart_shimmer_ui`.
* ⚡ High-performance standalone shimmer animation engine built with zero third-party runtime dependencies.
* 🌓 Automatic Light & Dark mode support that adapts seamlessly to `Theme.of(context).brightness`.
* 🧱 Ready-made primitive skeleton widgets:
  * `SmartShimmerBox` - Rounded rectangular placeholder.
  * `SmartShimmerCircle` - Circular avatar and badge skeleton.
  * `SmartShimmerText` - Multi-line paragraph placeholder with realistic line widths.
  * `SmartShimmerImage` - Aspect-ratio based image and banner placeholder.
* 📦 Ready-made complete UI layout presets:
  * `SmartShimmerListTile` - Avatar + title + subtitle skeleton list tile.
  * `SmartShimmerListView` - High-performance synchronized list view skeleton.
  * `SmartShimmerCard` - Vertical, horizontal, and compact skeleton cards.
  * `SmartShimmerGrid` - E-commerce and photo catalog grid skeleton.
  * `SmartShimmerProfile` - Complete user profile screen skeleton.
  * `SmartShimmerChat` - Chat message bubbles skeleton.
  * `SmartShimmerFeed` - Social media post feed skeleton.
* 🔄 `SmartShimmerBuilder` - Animated crossfade switcher between skeleton loading state and real loaded data.
* 🎨 Global theming support with `SmartShimmerTheme` and `SmartShimmerThemeData`.
* 💎 Smart Shimmer PRO showcase catalog and monetization support for full-screen template kits.
